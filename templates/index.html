Cloudflare DNS API
Как создать токен:
1. dash.cloudflare.com/profile/api-tokens
2. Create Token → шаблон Edit zone DNS
3. Zone Resources → Include → Specific zone → your-domain.com
4. Create Token → скопировать сюда
⚠ Не используйте Account API токены — нужен Zone токен
